# Verified sample data

The original six-record UI fixture remains in `frontend/src/data/records.js`. It is separate from the current 599-row database and is not used as an API-error fallback.

These records are retained as UI regression and offline demonstration data. They are not generated by the Phase 1 ingestion pipeline and must not be used as evidence that database persistence, entity resolution or row-level parsing is implemented.

The original 77 extraction rows are parser-seeded regression labels. Eleven additional extraction rows have primary source review. The original sixteen entity pairs are tuned regression examples. Forty additional real-corpus pairs include source hashes and serials; seventeen have applied primary review decisions. Twenty-three annotations are held out from review application. None of these files claims independent human review. Three ambiguous product pairs are excluded from binary metrics.
