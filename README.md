# CDSCO Regulatory Intelligence Demo

This is a static interactive prototype of the entity-centric CDSCO regulatory intelligence portal described in `PROJECT_KNOWLEDGE.md`.

The records, entity names, IDs, counts and quality metrics shown in the demo are illustrative. They must not be treated as live CDSCO data or as claims about the safety of a product or manufacturer.

## Run locally

Serve the `dist` directory with any static web server and open `index.html`.
